# Live Flight Tracker

A Java Spring Boot application for displaying live flight positions on an interactive map.

## Requirements

- Java 21

## Build and test

The project uses the Gradle Wrapper.

### Windows

```powershell
.\gradlew.bat build
```

### macOS / Linux

```bash
./gradlew build
```

## Tech stack

- Java 21
- Spring Boot
- Gradle
- JUnit
- GitHub Actions (planned)
